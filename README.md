# Twitter AI Auto Reply — Product Website

Official product landing page and interactive showcase for the [Twitter AI Auto Reply (Gemini Web)](https://github.com/gomedz/twitter-auto-reply) Chrome extension.

---

## 🌟 Overview

This repository contains the standalone product landing page, interactive reply simulator, feature breakdown, installation guide, and FAQ for **Twitter AI Auto Reply**.

- **Interactive Playground**: Test simulated reply generation across 6 distinct tones (*Thoughtful*, *Quick*, *Agree*, *Humorous*, *Question*, *Counter*).
- **Engine Comparison**: Explore how Gemini Nano on-device AI, Headless Direct sessions, and Web Tab automation operate.
- **Install Guide**: Visual step-by-step tutorial to install and load the extension unpacked.
- **Zero API Key Showcase**: Explaining how the extension works without requiring paid API keys.

---

## 🚀 Live Preview & GitHub Pages

To host this website on GitHub Pages:
1. Go to your repository **Settings** → **Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Under **Branch**, choose `main` and root `/`.
4. Click **Save**—your site will be live at `https://gomedz.github.io/twitter-auto-reply-window/`!

---

## 💻 Local Development

Run a local web server:

```bash
# Python
python -m http.server 8080

# Or Node / npx
npx serve
```

Visit `http://localhost:8080` in your browser.
